# 画活了 · 本机 AI 技术测试版

已连接 Poixe 服务端任务接口：用户自己的处理图＋家长确认设定 → 一次文字分镜 → 三次参考原画生图 → 四页技术预览。此版本不代表效果试验、审核或家庭试用验收通过。

## 启用真实 AI

在已经设置 `POIXE_API_KEY` 的终端、项目目录下执行：

```sh
npm run ai:configure
```

命令将环境变量写入本项目 `.env.local`（权限 600，不打印密钥，Git 忽略，静态服务不开放），保留其他配置。当前运行服务会在页面刷新/进入生成设置时读取它；已有密钥的替换需重启服务。也可以直接在设置密钥的终端执行 `npm run dev`，完全不写环境文件。

```sh
npm run dev
```

打开 http://localhost:5173 。新上传画作 → 描述可留空 → 确认本地记录及 AI 使用说明 → 点击“生成故事”。程序先保存原画，再直接进入生成进度，不再经过保存详情或二次设定页。“只保存原画”保留为次要入口；既有作品仍可从详情发起故事。样例作品仍走预设演示。

## 当前实现

- 保留浏览器原图及原始记录；发送前用 canvas 生成最大边 1024 的 JPEG 处理副本，移除文件元数据。授权前不上传图文，原声始终不发送。
- 服务端读取密钥；前端不接触密钥。文字使用 `gpt-5.2`，图像使用已完成单图真实调用的 `gemini-2.5-flash-image`。
- 使用 Poixe 官方列出的无 CDN 接口 `https://api-eu-central-1-dc8.poixe.com`；可通过 `POIXE_BASE_URL` 改为主接口或 dc15。无 CDN 线路此次尚未真实验证，不保证可用；不自动跨线路重试生成。
- 本机 `.local-data/jobs/` 保存任务、来源快照、阶段请求、结果与用量。最多一个未完成任务，每本最多四次生成调用，30 分钟截止。存储目录不在静态文件允许列表中。
- 提交幂等，浏览器刷新找回，已完成页面保存；中断先按原请求查询 Recoveries，结果不明时等待用户点击找回，不盲目重发。服务重启遇到未完成请求也先找回。
- 浏览器随机凭据用于任务归属检查，凭据保存在 IndexedDB；这不是正式家长登录。不同浏览器不能直接访问对方任务。Host、Origin 和 JSON 请求限制用于本机防护，服务仅绑定回环地址。
- 原画首页＋三页 AI 续画，来源与 AI 标识随阅读、PNG 分享、打印/PDF 保留。真实故事暂未接入单页 AI 调整，禁用原有模拟滤镜入口。
- 用户取消/删除后不继续交付迟到结果。删除会清除本机任务中的图文；已经发送的上游请求可能仍完成或计费，服务方暂存不会随本机删除自动清理。

## 仍未完成

完整上传→生成链路目前通过模拟供应商集成测试；真实凭据下已验证文字调用、通用提示词单图生成和中断结果找回。**真实参考图三页续画、无 CDN 线路、字符一致性和实际费用仍需本次联调。**

尚无正式内容安全审核、家长账户、云存储/备份、真实支付退款、真实调整权益或人民币预算执行。四次调用上限不等同 PRD 的 ¥5.00 预算；费用以服务方账单为准。完整留存、训练与跨境政策仍待核验，只用于授权测试素材。生成结果有“未人工审核”标识，不能作为正式家庭交付。

# 初始交互 Demo 说明（真实 AI 以本文开头为准）

根据《产品需求文档 V3.1》和《开发路线图 V1.0》制作的本地网页原型。重点演示“先保存原画，再自愿做故事”，不代表 M1 效果试验或 M2–M5 正式验收完成。

## 运行

需要 Node.js 18 或更高版本，不需要安装应用依赖。

```sh
npm run dev
```

浏览器打开 http://localhost:5173 。服务仅监听本机；使用 IndexedDB 持久保存当前浏览器的记录，清除网站数据会丢失内容。请使用 `localhost` 同一地址，`127.0.0.1` 属于不同存储来源。

## 可以体验

- 响应式画册、故事列表、筛选与日期排序。
- JPEG / PNG / WebP 图片选择、10 MB 限制、旋转和居中方形裁剪；原文件单独保存，编辑不覆盖原始字节。
- 标题、创作日期、孩子的话和家长补充；60 秒以内麦克风录音、试听与重录。录音没有转写，也不参与故事生成。
- 本地保存、刷新找回、查看详情、原图和文字下载、整册 JSON 备份、删除。
- 三套自行绘制的 SVG 示例素材；蓝色小狗带有完整四页示例，其他两幅可以体验设定、确认、排队、取消、离开和完成后找回。所有示例文字与画作均为预设，不是真实儿童记录或模型能力证据。
- 故事阅读、阅读位置保存、两次调整演示、预览后计次、采用与单次撤销、30 天期限检查。调整用本地色调滤镜表现，不使用模型。
- 整本四页打印排版（在浏览器打印对话框选择“另存为 PDF”）；PNG 分享预览和下载，保留演示标记，不含用户原话、原声或身份资料。
- “我的”中明确展示 ¥9.90 计划价格及购买未开放状态。

## 演示步骤

1. 打开“翻开四页示例”，翻到第二页，体验调整、采用、撤销、分享和打印。
2. 点击“留下一幅画”，上传图片、填写文字、确认本地存储说明并保存。刷新后再次查看，下载原图验证原文件独立保留。
3. 打开“会唱歌的花园”，选择“一起做个故事”，确认演示说明。可取消，或返回画册、刷新后找回演示任务。
4. 在“我的”导出 JSON 备份，或从作品详情删除单幅记录。

自传图片只支持记录，真实 AI 未接入，因此不会将预设图冒充为用户图片的生成结果。花园和火箭故事复用原插画展示叙事结构，不代表三张真实续画交付。免费演示不扣真实权益。

## 边界与后续接入

当前是纯前端本地原型：无登录/账户隔离、云存储、服务端鉴权、真实内容审核、供应商调用、真实支付退款、成本台账或小程序；不要用于真实家庭招募。演示任务通过时间戳在页面打开时恢复，不是后台工作进程。没有跨标签页并发控制。

正式开发应依路线图先完成授权效果试验和基础记录闭环，再接入模块化 API、关系数据库、私有文件存储及持久化任务队列。AI 告知需要填写真实供应商和政策；本地演示同意不等同正式 AI 授权。支付与退款验收之前购买保持关闭。

原始图片和音频保存在 IndexedDB 的 Data URL 中，适合 demo；正式环境需 Blob/对象存储、配额管理与权限校验。JSON 是数据备份格式，当前没有备份导入界面。

## 主体轻度润色 · 2026-09-24

新任务采用 `gentle-refinement-v1`：文字分镜先区分角色身份锚点与允许的轻度优化，再统一三页的角色设计。允许线条、轮廓、填色、非辨识性比例及神态的适度整理；保留身份、主色、轮廓特征、独创结构与童趣。适用于人物、动物、植物、物品和幻想生物，不默认套用大眼或萌宠形象。

第 3、4 页同时参考原画和第 2 页生成图，后者用于角色设计一致性，不用于复制背景或构图。增加参考图片会影响输入用量，但不会增加生图调用次数。原画首页、已生成故事不变；旧任务没有新版本标记时沿用原提示，避免恢复过程中切换设计规则。真实视觉效果仍需后续生成验证。

## 一次描述的录入流程

上传表单默认仅显示可选的“说说这幅画”，保存为家长描述，不标成孩子原话。名字从描述自动截取（未填写时使用日期名称），创作日期默认今天；自定义名字、日期、单独记录孩子原话和录音放在折叠的“更多记录”中。原有记录字段保留。

真实生成时直接展示并沿用已填写的描述，只需确认授权；修改故事方向为折叠的可选操作。没有描述也可保存，并采用明确显示的温和故事默认方向。完整家长描述仍发送给模型，不因简短设定的长度限制而丢失。

## 四宫格分享

分享 PNG 为 1600×1600 的完整四宫格，依次为原画、第 2、3、4 页；图片等比完整显示，保留已采用的色调调整与来源/AI 标识。三页续画保留旁白，原画格使用通用介绍，不默认带出孩子原话、昵称或原声。导出使用整本版本快照，预览和下载为同一文件。

### 多人生成与排队

默认同时处理 2 个故事，其余任务按提交顺序等待，页面显示排队位置；每个故事的后两张续画并行请求，因此默认最多同时请求 4 张图片。等待找回的任务在本轮请求结束后释放处理名额，不阻塞其他用户。重启会恢复已保存的队列；恢复请求仍优先找回原结果，不重复提交不确定的付费调用。任务目前仍以提交后的 30 分钟为总截止时间，包含排队时间。

在服务器 `.env.local` 添加 `STORY_CONCURRENCY=2`，重启 Node 生效。支持 1–8；应根据 POIXE 账号并发额度调整。该并发限制针对单个 Node 进程，当前文件存储方案不要启动多进程共享任务目录。等待队列不设人数上限，目前尚未实现公开试用所需的每日额度或请求频率控制。

验证：`npm test` 包括多人提交、FIFO 顺序、并发上限、排队取消、等待找回释放名额、所有权隔离、幂等及队列重启恢复。测试使用模拟服务，不代表上游实际吞吐量。
